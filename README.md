# Syllabus to Calendar

## Project Scope
My app helps students turn syllabus text into calendar events by extracting assignment, quiz, and exam dates, letting users review them, and exporting an .ics file.

## Problem
Students often check multiple course syllabi and manually copy deadlines into their calendars. This takes time and can lead to missed dates.

## Planned MVP
- Paste syllabus text into the app.
- Extract assignment, quiz, and exam dates.
- Review and edit the extracted events.
- Download an .ics file to import into a calendar.

## Out of Scope for the MVP
- PDF uploads.
- Direct calendar account integration.
- Automatic deadline updates.

## Status
Planning stage. The next goal is to build a working MVP before the next class.
